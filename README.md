# СкороМаркет

Курсовой проект: витрина продуктовой доставки с каталогом, корзиной, регистрацией, личным кабинетом, промокодами и админ-панелью.

## Как запустить

Для локальной проверки лучше запускать через небольшой статический сервер:

```bash
python -m http.server 8000
```

После запуска откройте:

```text
http://localhost:8000
```

## Что внутри

- `index.html` - главная страница сайта.
- `app.js` - логика каталога, регистрации, корзины, заказов и админ-панели.
- `styles.css` - оформление сайта.
- `assets/` - локальные фотографии товаров.
- `vendor/sql-wasm.js` и `vendor/sql-wasm.wasm` - SQLite для браузера.
- `vercel.json` - настройка корректной отдачи SQLite WASM на Vercel.

## Сохранение данных

В проекте реализована SQLite-база в браузере. Данные остаются на устройстве пользователя. Сохраняются:

- зарегистрированные пользователи;
- товары каталога;
- изменения из админ-панели;
- корзина и текущий пользователь.

## Личный кабинет и промокоды

После входа появляется кнопка `Кабинет`. В личном кабинете видны данные пользователя и история оформленных заказов.

Доступные промокоды:

```text
SKORO10
FOOD300
```

## Админ-панель

Кнопка `Админ` появляется только после входа под администратором.

Данные администратора:

```text
логин: admin
пароль: Skoro2026
```

Обычные пользователи после регистрации и входа видят только профиль, выход и корзину.

В ней можно добавлять, редактировать и удалять товары. Для фото указывается локальный путь, например:

```text
assets/dj-milk.webp
```

## Деплой на Vercel

1. Загрузите проект в GitHub-репозиторий.
2. В Vercel импортируйте репозиторий.
3. Framework Preset можно оставить `Other`.
4. Build Command и Output Directory можно не заполнять.
5. После деплоя сайт будет работать как статический проект, а SQLite будет сохраняться в браузере пользователя.
